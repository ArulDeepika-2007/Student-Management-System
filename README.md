# 🎓 Student Management System

A simple **Student Management System** designed to manage student information efficiently.
The system allows users to add, view, update, and delete student records through an easy-to-use interface.

## 📌 Project Overview

The Student Management System is a CRUD-based application that helps manage student details digitally.

Instead of maintaining student information manually, this application provides a simple way to:

* ➕ Add new students
* 👀 View student details
* ✏️ Update student information
* 🗑️ Delete student records
* 🔍 Manage student data efficiently

## 🚀 Features

* Student registration
* View all student records
* Update student details
* Delete student records
* Simple and user-friendly interface
* CRUD operations
* Responsive design
